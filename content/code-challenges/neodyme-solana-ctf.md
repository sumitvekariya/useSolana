These Solana CTF challenges help you learn smart contract security by finding and exploiting vulnerabilities. The collection includes challenges from various competitions and workshops, covering different security concepts in the Solana ecosystem.

## Available Challenges

- **Neodyme Workshop Levels 1-4**: A progressive series of challenges teaching Solana security fundamentals
- **Secret Store**: Learn about data privacy vulnerabilities
- **Legit Bank**: Explore financial contract security issues
- **Bugchain**: Find and exploit bugs in a blockchain implementation
- **Solfire**: Solana contract exploitation challenge
- **Darksols**: Smart contract security puzzle
- **Halborn CTF**: Security challenges from Halborn
- **Moar Horse 5**: Program exploitation challenge
- **Cashio Exploit Workshop**: Based on a real-world exploit
- **Solhana 1-3**: Series of progressive security challenges
- **Pool**: Advanced contract exploitation puzzle
- **League of Lamports**: Account security challenge

Each challenge simulates real-world vulnerabilities to help you understand common security pitfalls when developing on Solana.
