The Legit Bank challenge simulates a financial application built on Solana, where you'll identify and exploit vulnerabilities in banking operations. This challenge tests your understanding of financial security concepts in blockchain environments.

## Challenge Goals

- Understand account management and security in financial applications
- Identify vulnerabilities in transaction processing systems
- Learn about secure fund management in smart contracts
- Explore common attack vectors against financial protocols

Originally presented at ALLES CTF 2021, this challenge provides valuable insights into the specific security considerations necessary when building financial applications on Solana, including proper validation, transaction handling, and fund protection mechanisms.
